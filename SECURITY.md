# Security policy

## Supported versions

Only the latest release receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's **Report a vulnerability** button (Security tab of this repository) or write to contact@mooneyeswargame.com. Expect an answer within 7 days.

Never include a real OAuth token, client secret or account data in a report.

The threat model, scopes and token storage are described in [docs/SECURITY.md](docs/SECURITY.md).
